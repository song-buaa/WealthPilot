# WealthPilot v3.15.1 Release Evidence

Release date: 2026-08-18

Scope: Canonical Asset Classification Root Fix

## Root cause

Broker security type, vehicle type, and economic asset class were conflated. In particular, an IBKR security represented as `secType=STK` could be an ETF and must not default to an Equity economic exposure.

The canonical classifier now keeps these concepts separate. A verified conId/ISIN mapping or reliable Broker evidence determines ETF economic exposure; insufficient evidence fails closed to `UNKNOWN`.

## Canonical examples

| Instrument | Broker security type | Vehicle type | Economic classification |
| --- | --- | --- | --- |
| CSBGU3 / CBU3 | STK | ETF | FIXED_INCOME / SHORT_TERM_TREASURY |
| IB01 | STK | ETF | FIXED_INCOME |
| AAPL | STK | COMMON_STOCK | EQUITY |
| SPY | STK | ETF | EQUITY |

No ticker-only product hardcode is used as the classification authority.

## Human acceptance

- Self-use API returned CSBGU3 and IB01 as `FIXED_INCOME`.
- Portfolio UI displayed CSBGU3 and IB01 as 固收.
- Portfolio summary displayed 固收 15.8% and 权益 84.1%.
- API and UI were consistent.

## Safety

- Release closeout performs no Broker connection, order mutation, WhatIf, real market-data call, or real LLM call.
- No account identifier, credential, secret, or local database content is included in this release evidence.
- `v3.15.0` remains immutable.
