# 投资决策页面改版方案

> WealthPilot · 投资决策模块 · 开发执行稿  
> 版本：v0.3（定稿）| 日期：2026-04-03  
> 状态：可交付 Claude Code 执行

---

## 一、改版目标

当前页面首屏只有一句引导语和三条胶囊问题，没有完成"帮用户发起高质量投资问题"的任务。

**本次改版将页面从"等用户输入的聊天页"升级为"主动引导用户发起问题的决策工作台首页"**，具体实现三件事：

1. 用意图分类卡片取代零散胶囊，让用户知道能问什么
2. 结合持仓数据生成个性化推荐问题，让用户感受到"AI 懂我"
3. 重建右侧区域，从空白占位变为有层级的"决策依据区"

---

## 二、页面整体结构

### 布局划分（维持现有左右分栏，不改变整体框架）

```
┌─────────────────────────────────────────────┬────────────────────────┐

│                                             │                        │
└─────────────────────────────────────────────┴────────────────────────┘
```

## 三、各区域详细规格

### A. 页面标题区

#### 内容

```
投资决策                              ← 主标题，保持现有样式
告诉我你的投资想法，我会结合持仓、        ← 副标题（引导语），替换现有文案
风险、纪律和已有观点，为你做一次
结构化评估。
```

#### 引导语说明

采用以上单一版本，不提供候选。设计原则：
- 用用户视角（"你的"）而非系统视角（"五个维度"）
- 覆盖产品核心能力（持仓 / 风险 / 纪律 / 观点）
- 语气是邀请感，不是拦截感

#### 样式要求

- 主标题：保持现有字号和样式
- 副标题：比主标题小 2 档字号，使用次要文字色（灰色），不加粗
- 原有"AI 辅助 · 纪律守护 · 多轮对话"标签行可保留，不强制移除

---

### B. 个性化推荐区

#### 区域标题

- 有持仓数据时显示：`为你推荐`
- 无持仓数据时显示：`你可以这样问我`

#### 触发条件与分支

页面加载时**同步读取**投资账户总览持仓数据：

```
if 持仓数据存在 且 holdings.length >= 1:
    → 执行 B-1 个性化推荐模式
else:
    → 执行 B-2 通用推荐模式

if B-1 执行过程中发生异常（字段缺失 / 逻辑错误 / 返回空值）:
    → 自动降级为 B-2 通用推荐模式
```

#### B-1：个性化推荐模式

**展示数量**：固定 3 条

**问题生成规则**：

按以下优先级从持仓数据中选取标的，套入对应骨架：

| 优先级 | 选取标准 | 问题骨架 |
|--------|----------|----------|
| 1 | `positionRatio` 最高的标的（第一重仓） | `[标的名称] 目前仓位偏重，我需要重新评估一下吗？` |
| 2 | `unrealizedPnl` 为负且绝对值最大的标的 | `[标的名称] 目前处于浮亏状态，这个持仓还值得继续拿吗？` |
| 3 | `recentReturn` 拖累最明显的标的（若字段不存在则取第二重仓） | `最近收益不太理想，主要是 [标的名称] 这部分拖累了吗？` |

**优先级 2 异常兜底**：若所有持仓均为盈利（无浮亏标的），则改取 `recentVolatility` 最高的标的，骨架改为：
```
[标的名称] 近期波动比较大，我这部分仓位需要做什么调整吗？
```

**优先级 3 异常兜底**：若找不到明确拖累标的且 `recentReturn` 字段不存在，则取第二重仓，骨架改为：
```
如果新增一笔资金，[标的名称] 在现有组合里还值得优先考虑吗？
```

**语气生成约束**：

- ✅ 问题语气必须引导用户**评估和思考**，使用"重新评估"、"还值得继续拿"、"值得优先考虑"等中性措辞
- ❌ 禁止出现"要不要减仓"、"是否清仓"、"可以加仓"等含明确买卖方向的措辞
- ❌ 禁止对没有量化依据的标的生成"偏高"、"偏低"等主观判断（仓位占比数据除外）
- ❌ 禁止为同一标的生成两条推荐问题

#### B-2：通用推荐模式（无持仓数据或降级时）

固定展示以下 3 条，不做随机：

```
1. 如果我准备开始配置权益资产，第一步应该怎么做？
2. 稳健型投资者应该怎么理解股债的仓位比例？
3. 同样是买基金，主动型和指数型怎么选？
```

#### 交互行为（B-1 和 B-2 通用）

- 点击任意一条推荐问题 → 文字内容**填入底部输入框**，不自动发送
- 填入后输入框自动获取焦点，光标定位到文字末尾
- 填入后推荐区保持展示，不收起

### C. 意图分类区

#### 区域标题

`按问题类型开始`

#### 展示形式

**2 列卡片网格**，共 5 张卡片。第 5 张（投教通用）独占一行居左，右侧留空。

#### 卡片默认状态

- **默认展开第一张**（单标的决策），其余 4 张默认折叠
- 折叠态展示：分类图标 + 分类名称 + 问题数量角标（如 `3`）
- 点击卡片标题行 → 展开显示问题列表；再次点击 → 折叠
- **手风琴模式**：同时只允许一张卡片处于展开状态

> 默认展开"单标的决策"的原因：这是最高频的意图类型，首屏立即可见问题，更符合"主动引导"而非"等用户翻目录"的设计目标。

#### 各分类问题内容

每张卡展开后显示以下问题，每条独立一行，可点击：

**单标的决策**（3 条）
```
现在这个时机，适合买入某只标的吗？
我持有的某个标的，目前还值得继续拿下去吗？
我想补仓某个标的，但担心仓位太重，这种情况怎么判断？
```

**组合评估**（3 条）
```
帮我看看我现在的整体持仓，风险大不大？
我的持仓是不是有点押注太集中了？
我现在这套组合，还需要做哪些结构调整？
```

**资产配置**（3 条）
```
我目前的大类资产配置，比例是否合理？
如果手里多一笔闲钱，优先补现有组合还是重新分配？
我的固收和权益比例，需要调整吗？
```

**收益分析**（3 条）
```
最近一段时间收益不理想，主要问题出在哪？
我的组合里，哪些部分拖累了整体表现？
我最近的回撤，在正常范围内吗？
```

**投教通用**（3 条）
```
什么情况下应该对持仓做再平衡？
集中持仓和分散持仓，各自有哪些风险？
为什么追求高收益通常意味着要承担更大波动？
```

> 问题文案原则：专业骨架 + 口语化表达，通用表述（不预填具体标的名称），与 B 区个性化形成区分。

#### 交互行为

- 点击任意一条问题 → 文字内容**填入底部输入框**，不自动发送
- 填入后输入框自动获取焦点，光标定位到文字末尾
- 填入后当前展开的卡片保持展开状态，不收起

---

### D. 底部输入框

#### Placeholder 文字

```
输入你的投资想法，例如"腾讯仓位有点重，想评估一下是否需要调整"
```

#### 状态规则

| 状态 | 触发条件 | 表现 |
|------|----------|------|
| 空态 | 输入框无内容 | 发送按钮置灰，不可点击 |
| 有内容态 | 输入框有任意内容（含模板填入） | 发送按钮激活，可点击 |
| 发送中 | 点击发送后，等待响应 | 发送按钮变为 loading 态，输入框禁用 |

其余行为（Enter 发送 / Shift+Enter 换行）保持现有逻辑不变。

### E. 右侧决策依据区

#### 命名变更

`决策链路` → `决策依据`

#### 区域头部（固定展示）

```
决策依据                             ← 标题，字号与左侧"投资决策"主标题平齐
本次分析的关键数据与推理依据              ← 副标题，小字灰色
```

**对齐修复**：右侧区域顶部须与左侧"投资决策"主标题在同一水平线（当前存在错位，需修复）。

#### 状态一：空状态（页面初始加载，未发起任何提问时）

展示分析机制说明：

```
发起一次投资问题后，我会按以下步骤为你分析：

① 识别问题类型
   判断这是单标的、组合、配置还是收益类问题

② 读取账户数据
   调取相关持仓信息、仓位占比与盈亏状态

③ 检查纪律约束
   核对是否触发投资纪律中的风险规则

④ 分析市场信号
   结合投研观点与风险信号进行综合评估

⑤ 生成结论
   输出判断依据与建议方向

分析完成后，本次判断的关键依据将展示在这里，
让结论更透明、更可追溯。
```

样式：步骤序号小字，步骤标题正常字号，步骤说明灰色小字，整体偏轻量。

#### 状态二：结果态（AI 回答完成后）

分三层展示，从上到下：

**第一层：结论摘要**

```
┌──────────────────────────────────┐
│  当前结论                          │
│  可评估，暂不建议追加仓位             │
│                                  │
│  当前风险提示  ●●●○○  中等偏高      │
└──────────────────────────────────┘
```

> **"当前风险提示"定义**：指本次决策动作在当前持仓背景下的综合风险判断，综合考虑仓位集中度、近期波动率和纪律约束命中情况，由规则引擎输出，不由 LLM 自由生成。共五档：低 / 较低 / 中等 / 中等偏高 / 高。

**第二层：关键依据标签**

展示 3–5 个标签，chip 样式，每个标签一行：

```
· 仓位占比偏高（18%）
· 集中度超出纪律阈值
· 近期波动率上升
· 无新增利多观点支撑
```

标签颜色：风险类用橙/红色调，中性信息用灰色，正向信号用绿色。

> **标签来源约束**：关键依据标签优先来自结构化字段和规则引擎判断结果，不由 LLM 完全自由生成。LLM 负责组织文字表达，标签内容须有明确数据或规则来源。

**第三层：详细分析链路（默认折叠）**

折叠态文字：`查看完整分析过程 ›`

展开后：

```
问题识别     单标的决策 · 腾讯控股
数据读取     仓位 18%，浮盈 12%，近 30 日波动率 ↑
纪律检查     集中度偏高，未触发硬性止损规则
信号分析     波动中等，近期情绪偏弱
观点匹配     当前无强利多观点
最终判断     不建议继续追高，可等待更优入场位置
```

#### 状态切换规则

| 时机 | 右侧状态 |
|------|----------|
| 页面初始加载 | 空状态 |
| 用户发送问题，AI 开始回答 | **保留上一轮结果态**（若有），顶部显示轻提示：`正在生成本次分析…` |
| AI 回答完成 | 整体替换为本轮新结果态 |
| 首次提问（无上一轮结果） | 发送后保持空状态，AI 回答完成后切换为结果态 |

## 四、数据依赖说明

### B 区个性化推荐所需字段

从「投资账户总览」模块读取：

| 字段 | 类型 | 用途 |
|------|------|------|
| `holdings[].name` | string | 标的名称，用于问题填槽 |
| `holdings[].positionRatio` | number | 仓位占比，判断第一/第二重仓 |
| `holdings[].unrealizedPnl` | number | 浮动盈亏，判断浮亏最大标的 |
| `holdings[].recentReturn` | number | 近期收益贡献，判断拖累标的（选填，缺失时用第二重仓替代） |
| `holdings[].recentVolatility` | number | 近期波动率，优先级 2 兜底时使用（选填） |

### 无数据判断逻辑

```
if holdings === null || holdings === undefined || holdings.length === 0:
    → B-2 通用推荐模式
else:
    → B-1 个性化推荐模式（异常时降级为 B-2）
```

## 五、不在本次改版范围内

| 内容 | 原因 |
|------|------|
| "继续上次问题"入口 | 依赖会话历史持久化，当前未实现 |
| 模板问题"换一批"功能 | 需模板库扩充，后续迭代 |
| 右侧结果态逐节点动画 | 视觉增强，不影响功能，后续打磨 |
| 意图扩展至 6–8 类 | 业务扩展，当前以 5 类为准 |

## 六、实施优先级

| 优先级 | 模块 | 具体内容 |
|--------|------|----------|
| P0 | A 区 | 引导语文案替换 |
| P0 | C 区 | 意图分类卡片网格（折叠/展开/手风琴/默认展开第一张/点击填入输入框） |
| P0 | D 区 | Placeholder 替换 + 按钮状态逻辑（空态置灰 / 有内容激活 / 发送中 loading） |
| P1 | B 区 | 个性化推荐区（数据读取 → 填槽生成 → 异常降级 → 通用兜底） |
| P2 | E 区 | 决策依据区重建（命名变更 + 对齐修复 + 空状态 + 结果态三层结构 + 状态切换） |
