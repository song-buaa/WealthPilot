# v3.10 IBKR 下单接入 — 完整验证报告（封板版）

## 1. 范围回顾

### 本期做了什么
IBKR（Interactive Brokers）下单接入：通过 ib_async 2.x 封装 BrokerAdapter，
接入 OrderManager 下单/撤单/查询全链路。在 Paper 账户（DUQ629797）完成端到端验证，
在实盘账户（U3831209）完成连接校验 + 拒单链路冒烟。

### 明确没做的（PRD §1 Out of Scope）
- IBKR 持仓拉取/同步（持仓仍走老虎/雪盈/国金）
- 条件单（CONDITIONAL_LIMIT，闸门 3 拒绝）
- Market 单（仅支持 LIMIT）
- 自动登录保活（TWS/Gateway 需手动启动并保持登录）
- A 股交易（闸门 2 拒绝，A 股走国金 QMT）

## 2. 逐里程碑结论 + 证据

### M0: cancel 真撤单

**修复 bug**: cancel_order 之前只改本地状态，不通知券商。
修后分流逻辑（5 分支）：无 broker_order_id → 仅本地；已终态 → 拒绝；

**真连证据**: M3 端到端 audit_log 记录 `cancel_broker_responded: broker_accepted=true`，

**Inactive/errorCode 判定纪律**:
- REJECTED_ERROR_CODES = {200, 201}（仅探针实测值）
- 200: 合约无效 → 直接 Cancelled（不经 Inactive）
- 201: 保证金/权益不足 → Inactive，errorCode 经 error callback 异步到达
- errorCode 双来源合并：trade.log + error callback 任一命中即判 rejected
- keyword fallback 降级为 unknown（不判 rejected 终态）
- **实盘确认**: 201 经 callback→Inactive→rejected 链路在实盘成立（U3831209, errorCode=201）

## 4. 已知局限 / 遗留

1. **港股未真连验证**: US/SMART/USD 经探针+端到端+实盘验证；
   HK/SEHK/HKD 仅有代码映射和闸门 2 白名单，未在 paper 或实盘真连下过 HK 单。

2. **keyword fallback 降级后覆盖面**: Inactive + 无实测码时只判 unknown 待人工。
   如果未来出现新的拒单 errorCode（如 203/104/106），在探针实测前只能走 unknown → poller 轮询。

3. **Filled 未验证**: paper 和实盘下的单都是远低于市价的不可成交单，
   Filled 状态映射和 avg_filled_price 回填未经真实成交验证。

4. **自动登录保活未做**: TWS/Gateway 需手动启动并保持登录。
   断连后 adapter 不自动重连（需手动重启应用）。

5. **risk_engine 无 IBKR 感知**: 投资纪律模块的 risk_engine 不区分 broker，
   下单前的纪律校验（仓位上限等）对 IBKR 订单和 Tiger 一视同仁。
   这是预期行为，但需确认 symbol 格式兼容。

6. **_error_codes 映射不持久**: adapter 重启后 _error_codes dict 清空。低频边缘场景。

7. **happy path 实盘未验证**: 成功挂单→真撤单路径在 paper（M3）完整验证通过，
   但实盘因 IB 账户级限制（Equity < $100K 不允许开新仓）两笔都被拒，未能验证。
   见下方「已知账户限制」。

### 已知账户限制

实盘冒烟发现：IB 实盘账户（U3831209）当前 Equity with Loan Value = $4,262，
远低于 IB 要求的 $100,000 最低权益门槛。低于此门槛时，IB 不接受任何新仓开仓，
仅允许对冲（hedge）操作。

- 该限制是 IB 账户级规则，代码侧无法绕过
- Paper 账户不触发此限制（模拟百万资金）
- 实盘要开新仓，需入金至 $100K 以上
- 对已有仓位的操作（减仓、平仓）不受此限制影响
