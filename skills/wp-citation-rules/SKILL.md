# wp-citation-rules

输出引用规则。

## 类型说明

本 Skill 是 `prompt_inject` 类型——**不通过函数调用执行**，而是把规则文本注入到
其他 Skill（特别是 wp-reasoning）的 LLM prompt 里。

## 9 条数据引用规则

### 关于纪律数据
1. 纪律校验结果中的"上限"是风险控制的硬性边界，不是建议仓位
2. 如果当前仓位未超过纪律上限，不得说"超过上限"
3. 引用纪律数据时，格式为：「您的单标的纪律上限是 X%，当前仓位 Y%，[已超出/距上限还有 Z 个百分点]」

### 关于基本面和投研信息
4. research 字段中有具体数字的，必须直接引用原始数字（如"净利润同比下降 94%"），禁止替换为"大幅下滑"等模糊表述
5. 引用优先级：[用户资料] > [第三方数据] > [联网参考]
6. [用户资料] 是用户审核过的观点，优先引用且不附链接
7. [第三方数据] 引用时句末附"（据公开数据）"
8. [联网参考] 引用时句末附"（据公开信息）"
9. 分析师评级如果存在（如"大和重申买入"），在核心依据中一条带出

## 4 档时效性规则

基于每条观点末尾的"数据截至 YYYY-MM-DD"标注，对照 current_date 字段判断：

| 数据时效 | 处理方式 |
|---------|---------|
| 7 天内 | 正常引用，无需额外说明 |
| 8-30 天 | 句末注明"（据 YYYY-MM-DD 数据）" |
| 30 天以上 | 只引用其中的长期逻辑，不引用具体数字 |
| 90 天以上的[第三方数据]新闻类 | 忽略不引用 |

注：[用户资料] 来源不受时效规则限制。

## 链接强制规则

- 有 [ref:url] 标注的内容，引用时句末必须附 `[[来源]](url)`
- 不得对没有 URL 的内容伪造链接
- 每条引用数据最多附一个链接
- [用户资料] 标注的内容不附链接
- 日期标注（如 [2026-03]）不要出现在 chat_answer 正文中

## 注入方式

v3.0 当前阶段：规则在 `decision_engine/llm_engine.py` 的 5 个 prompt 常量里写死。

v3.1 演进：本 SKILL.md 的 body 内容会被 SkillsLoader 读取，注入到 wp-reasoning
调用 LLM 时的 system prompt 里，prompt 模板里只保留意图特定的部分（输出 schema /
章节结构等）。

## 案例驱动迭代痕迹

每条规则都对应历次 case 驱动迭代修复的真实 LLM 输出问题：
- 规则 1-3：防止 LLM 误读纪律数据（"超过上限"等）
- 规则 4：防止 LLM 模糊化关键数字
- 规则 5-9：防止 LLM 伪造来源或来源混乱
- 时效性规则：防止 LLM 引用过期数据
- 链接规则：防止 LLM 伪造链接
