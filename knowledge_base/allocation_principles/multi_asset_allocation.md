# 多元资产配置

## 核心理念

资产配置的本质不是预测涨跌，而是让不同资产各司其职：货币保流动性，固收稳底盘，权益求增长，另类分散风险，衍生作战术工具。不同资产解决不同问题，缺一不可。

资产配置是投资组合的"骨架"——个股选择再好，如果骨架结构不合理（比如 95% 权益、0% 现金），一次系统性风险就可能造成无法承受的损失。正确的资产配置不保证赚最多，但能保证在大多数市场环境下活得够久。

## 五大资产类别详解

### 1. 货币类（流动性储备）

**目的**：应对日常支出和突发资金需求，确保不在不利时点被迫卖出其他资产。

**典型工具**：货币基金、银行活期存款、短期国债逆回购。

**配置建议**：保持等值于 3-6 个月生活费的绝对金额，不按比例计算。投资组合中额外保留至少 10% 的现金类资产作为"弹药"，用于市场大幅回调时的加仓机会。

### 2. 固收类（稳定底仓）

**目的**：提供可预期的现金流，降低组合整体波动率，在权益资产下跌时起到缓冲作用。

**典型工具**：国债、政策性金融债、信用债基金、存单。

**配置建议**：目标区间 20%-60%，与权益类互补。风险承受能力较低的投资者可将固收类提升到 40%-60%；风险承受能力较高的投资者可压缩到 20%-30%。注意信用风险——优选高信用等级、中短久期品种。

### 3. 权益类（长期增值引擎）

**目的**：通过持有优质企业的股权分享经济增长，是长期实际收益的主要来源。

**典型工具**：A 股、港股、美股个股或 ETF，偏股型基金。

**配置建议**：目标区间 40%-80%，依据投资者风险偏好和投资期限调整。权益配置的核心不是择时，而是保持在合理区间内持续暴露。跌幅超过目标下限时考虑加仓，涨幅超过上限时考虑减仓，但不追求精确回到目标值。

### 4. 另类资产（分散风险）

**目的**：与传统股债资产低相关，在极端市场环境下提供对冲保护。

**典型工具**：黄金（实物 / ETF）、REITs、大宗商品基金。

**配置建议**：0%-10%，非核心仓位。黄金是最常用的另类配置——历史上在股市大跌和通胀周期中表现较好。REITs 提供不动产敞口但流动性受限。另类资产的目的不是追求高收益，而是"当其他东西都跌的时候，它可能不跌甚至涨"。

### 5. 衍生工具（战术对冲）

**目的**：用于特定场景下的风险对冲或策略性收益增强，不是常规配置工具。

**典型工具**：股指期权、个股看跌期权（保护性看跌）。

**配置建议**：0%-10%，受投资纪律严格约束。WealthPilot 的投资纪律明确规定：期权列为"绝对禁止"类别（Level 0），杠杆类工具有明确的杠杆率上限。只有在充分理解期权定价和风险暴露的前提下，才考虑用于下行保护。

## 配置原则

1. **不把鸡蛋放在一个篮子里**：单一资产类别占比不应超过 80%，这是纪律约束的硬上限
2. **流动性优先**：保持至少 20% 的货币/固收仓位应对突发需求
3. **按目标而非情绪配置**：投资目标和风险承受能力决定配置比例，不随市场情绪漂移
4. **知行合一**：配置方案确定后，严格执行，不因短期市场波动随意调整。偏离度超阈值时走再平衡流程，而非凭感觉操作
