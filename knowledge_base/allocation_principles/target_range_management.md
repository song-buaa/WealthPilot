# 目标区间管理

## 核心理念

每类资产都有自己的目标区间，资产配置的重点不是判断短期涨跌，而是让整体结构长期保持在合理范围内。用"区间"而非"精确值"作为目标，给配置留有弹性，避免因追求精确而频繁操作。

## 区间 vs 精确值

传统资产配置建议常给出"权益 60%"这样的精确目标。但精确目标有两个问题：

1. **执行焦虑**：当前权益是 58%，需要操作吗？62% 呢？精确目标让每一个偏离都像需要纠正的"错误"
2. **过度交易**：为了维持 60.0% 的精确目标，可能每周都要调整，交易成本累积远超收益

WealthPilot 采用区间目标（如权益 40%-80%），核心优势：
- **心理空间**：在区间内的任何比例都是"正确的"，减少不必要的焦虑
- **减少操作**：只有超出区间边界时才考虑操作，大幅降低交易频率
- **适应市场**：牛市中权益自然涨到区间上沿，熊市中自然降到下沿，两者都是可接受的状态

## 目标区间参考

| 资产类别 | 目标区间 | 说明 |
|---------|---------|------|
| 权益类 | 40%-80% | 依据投资者风险偏好调整。激进型偏上限，保守型偏下限 |
| 固收类 | 20%-60% | 与权益类互补，保持平衡。退休临近的投资者应逐步扩大固收区间 |
| 货币类 | 保持最低限额 | 至少覆盖 3-6 个月生活费，投资组合中保留 10%+ 现金类 |
| 另类 | 0%-10% | 用于分散风险，非核心仓位。0% 也是合理选择（不做不扣分） |
| 衍生品 | 0%-10% | 仅限对冲用途，受纪律严格约束。对大多数投资者建议 0% |

## 区间调整时机

目标区间不是永远不变的，以下情况应考虑调整：

**人生阶段变化**：退休临近时，逐步收窄权益区间（如从 40%-80% 调整到 30%-60%），同时扩大固收区间。这不是一次性操作，而是用 3-5 年逐步过渡。

**风险承受能力变化**：如果发现自己在权益 70% 时晚上睡不好觉，说明权益上限定高了。诚实面对自己的风险承受能力，调整区间上限到一个"能安心睡觉"的水平。

**市场环境极端变化**：在极端估值环境下（如全市场 PE 创历史新高），可以临时收窄权益上限；在极端低估时，可以临时放宽下限。但这种调整应谨慎，避免变成"预测市场"。

## 区间与纪律的联动

WealthPilot 的目标区间应与投资纪律模块的阈值保持一致，避免自相矛盾。具体而言：

- `asset_allocation_ranges` 中的 `equity_min` / `equity_max` 定义了权益类的纪律边界
- 当配置偏离超出区间时，系统的偏离度告警会触发，建议再平衡
- 如果调整了纪律模块中的阈值，目标区间的参考值也应同步更新

**一个反面教材**：纪律说权益上限 80%，但实际配置目标是"权益尽量多"——这就是自相矛盾。正确的做法是让配置目标落在纪律区间内，纪律是配置的"外围防线"。
